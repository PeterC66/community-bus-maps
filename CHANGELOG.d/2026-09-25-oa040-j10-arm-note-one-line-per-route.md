- **Re-vendored `engine/area/gen_external_radial.js` and added `engine/arm_note.js`, from claude-skills#127 for buses-data OA-040 J10.** The note under a town's external legend, which says which routes leave town on two arms, used to be one run-on paragraph that read as a single sentence. Each route now starts its own line and its number is bold. A hand-written `externalNote` is still one paragraph and is unchanged. The note's logic lives in the new module `arm_note.js`, which the generator requires at load, so it is vendored in the same commit and listed in `engine/vendored.json`. The towns whose external sheet moves are Chatteris, March, Soham, St Ives, The Shelfords, Whittlesey and Wisbech. In St Ives and The Shelfords the legend panel also moves, and the move clears it off route labels. Both portal fixtures are byte-identical, because `verify:area` runs the St Ives pack's own generator and that pack is still current against St Ives' newest render. So `verify:area` and `verify:place` do not move.
