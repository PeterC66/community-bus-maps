title: "The editor spine's API is a plugin, and the two guards behind its door differ by exactly one role"
---

The fourth and largest cut along `src/server.js`'s own banners (`buses-data` OA-231, Tier 4.4 of the 2026-09-01 codebase review). Fourteen routes moved to `src/routes/editor.js` under the prefix `/api/maps`; `server.js` 1,998 → 1,573 lines, from 3,371 before the admin cut. **The route table is byte-identical to the pre-split snapshot** — `scripts/route-table.json` was recorded from the UNSPLIT server and `test-admin-plugin.mjs` still owns it — and the line-by-line comparison reports **436 lines out, 436 in, with 32 differing**: the fourteen route paths, thirteen guard lines, and the operator-token route's own comment.

- **One guard, not fourteen.** Each handler used to open with its own `requireUser()` call; the plugin carries it as a `preHandler`, so a fifteenth route cannot forget it (portal-src F8). The single exception is declared as route config the guard reads — `GET /api/maps` admits the read-only `OPERATOR_TOKEN` (OA-203), the same shape `GET /api/admin/worklist` already used. The substitution is exact rather than merely equivalent: `requireUser()` RETURNS `req.user`, so `const user = req.user` in a handler the hook has already admitted is the same value the call produced.
- **The door is the weak half, on purpose — and here there are TWO strong halves.** `requireUser` establishes only that somebody is signed in. What matters is per-request because it needs the map: `loadOwnedMap()` (the map's own customer, or an admin) on eleven routes, `loadReadableMap()` (the same plus any platform approver) on two. Both stay in the handlers. A cut that hoisted the cheap guard and lost the per-map one would pass every *anonymous is refused* assertion ever written while letting any signed-in customer save over, publish or unlist another organisation's map.
- **Two guards that differ by one role are the easiest thing in the file to get wrong, in either direction, and neither direction is visible from an anonymous request.** Widen the read rule onto the owned routes and every approver can edit eleven routes' worth of maps they do not own; narrow the owned rule onto the read routes and the publish gate stops working, because an approver can no longer open the sheets they have been asked to review. `test-editor-plugin.mjs` asserts both directions on every route; `prove-red-editor-plugin.mjs` breaks the pair both ways, and those are arms four and five of eight. All 8 caught for their own reason, control green.
- **`prefixTrailingSlash: 'no-slash'` is load-bearing, and the measurement changed the assertion.** Fastify's default for a route path of `/` inside a prefixed plugin also registers `/api/maps/`, which the unsplit server never had — the one way this cut could silently ADD to the route table. Measured rather than reasoned: the twin arrives as `HEAD /api/maps/` and **not** as `GET /api/maps/`, so the obvious spelling of that check would have passed while the table had grown. The assertion asks about the path, not the method.
- **`GET /api/poi-glyphs` deliberately did NOT move.** Same audience, same guard, but it is not in the `/api/maps` subtree — it is our own pictogram artwork, map-independent by construction — and a prefix that overstates what a file governs is a claim a later reader acts on. It keeps its own `requireUser()` call in `server.js`, and the new test checks it there, because a route nobody moved is a route nobody is now responsible for.
- **Two existing suites followed the code, and one of them is a census that had to change its number.** Four source-level assertions in `test-p7.mjs` now read `src/routes/editor.js`; the path one can no longer see the whole URL from inside a plugin, and says so — `route-table.json` is what holds that. `test-operator-token.mjs` asks a closed question of every file under `src/`: the token is now consulted in three places, not two, because the editor plugin's guard has to admit the tokened call the way the admin plugin's does. Both halves of that exception are asserted, and `prove-red-operator-token.mjs`'s three stale anchors were re-pointed rather than relaxed.

`npm test` 48 run, 0 failed, 2 excluded (46 before). Neither new file needed a workflow edit — `npm test` globs `scripts/test-*.mjs` and `prove-red-*.mjs` and takes each command from the `package.json` script that owns it.
