date: 2026-08-27
title: "The documentation tracker held the only pointer to an open legal gate"
---

- **`docs/DOCUMENTATION-PLAN.md` was about to be archived, and it should not have been.** A documentation sweep across `buses-data`, this repo and the ops folder looked for documents that are historic only, using one test: a document is live if an undeleted `OA-nnn.md` or a top-level README still points at it. This file passed every surface reading of "finished" — its own header says **"✅ all tiers built 2026-07-25 (this doc is now the tracker)"**, and it is written against `0.8.0-P7` when the portal is `0.9.4-pilot`. It is also the **only** place in either repo describing two pre-launch legal gates. Archiving it would have taken both with it.
- **Of the two, one was already done and the tracker had never caught up.** G2's outstanding item was "add the data-controller identity before launch". `public/legal.html:38` has named Peter Cooper as the data controller for some time. Marked done, verified rather than assumed. G3's "propagate the footer Terms link to the other shopfront pages" was likewise already true — all 15 pages in `public/` carry it, checked one by one.
- **The other is real and is visible on the live site.** `public/terms.html:94` renders *"These terms are governed by the law of England and Wales, and its courts have jurisdiction."* followed by a `<span class="muted">[To confirm.]</span>` — a bracketed editorial note, published, on a site that has been open to search engines since 2026-08-21. It is the only bracketed placeholder anywhere in the shopfront; every `*.html` in `public/` was swept. Alongside it, `terms.html` is a non-lawyer draft that has never had a legal review. Nothing is in force — there are no customers — but it is the document a first customer would be asked to accept.
- **That work is now tracked as `OA-138` in `buses-data`**, and this file carries a line saying it must not be archived until OA-138 closes. **No page content changed in this commit** — the placeholder is deliberately left in place for Peter to confirm the jurisdiction rather than have it confirmed on his behalf.
- **The shape worth remembering:** a tracker that says it is finished can still be the sole custodian of unfinished work, and its claims age independently — two items in one block, one closed months ago and one live, indistinguishable without opening the artefact each described.
