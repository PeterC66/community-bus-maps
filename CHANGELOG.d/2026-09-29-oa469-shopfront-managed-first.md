- **The homepage's *How it is meant to work* now describes the managed service (buses-data OA-469).** Its four steps are: tell us the place, we build it and email it, you tell us if it is right, and we publish it and keep it current. A note under them offers a sign-in to the editor to any organisation that would rather make changes itself. The page description no longer calls the service "self-serve", and the outputs section says "tell us which you need" rather than "turn on".
- **The FAQ's *What can I change myself?* becomes *Do I have to edit the map myself?*** The answer is no: we email the sheets and a reply is all we need. The editor is described second, as an option. *How up to date are the maps?* and the missing-landmark answer now say what a managed customer does before saying what an editor user does. *Who can apply?* no longer says an account is set up.
- **The opportunity page's portal card is now *A managed service, not a folder of files***, with the editor described as the option. No price is named anywhere (OA-029).
