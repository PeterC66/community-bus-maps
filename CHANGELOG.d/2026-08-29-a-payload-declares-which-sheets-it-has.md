---
date: 2026-08-29
title: "A payload declares which sheets it has"
---

- **The portal decided an output was renderable from whether a GENERATOR resolved, and it got both possible answers wrong (OA-009).** St Ives Bus Station has no external radial — the solver cannot fan its eight spokes without putting Cambridge in the wrong direction, and the skill's own board reports its external as `-`. The portal rendered a 20,563-byte `external.svg` with real spokes anyway, offered it, and it had to be switched off by hand with a `PATCH outputs`.
- **The truth was never far away: an S5-render folder holds one `<base>.svg` per sheet the skill actually built.** That is the same set the S4 manifest record lists, and unlike the manifest it travels with the folder — which matters, because a delivery scps only `--src` to the host and the manifest never goes with it. So `import-map.mjs` and `propose-update.mjs` now write `sheets.json` beside the payload, and `resolveGen()` reads it.
- **MEASURED across the whole estate before making it, because it changes what a map is offered.** Of the 20 payloads under `Areas/` and `Places/`, the declaration changes the answer on **exactly one** — St Ives Bus Station, which loses its external. Every other map is offered precisely what it is offered today.
- **An absent declaration means "don't know", not "nothing".** A source folder with no sheets in it writes nothing at all, and a map imported before this keeps the behaviour it has until its next refresh writes one. That trap has its own assertion, watched go red.
- **The second half is a requirement that belongs to ONE generator rather than to the output.** `gen_external_places.js` aggregates `destinations` from routes.json; handed a payload with none it exits **0** and draws a radial with no spokes — a blank sheet offered as "Where those buses go", which is worse than an error. Putting `requiresConfig: 'destinations'` on the OUTPUT was the wrong fix and was measured as such: **10 of the 20 payloads have no usable `destinations`, and 8 of those are town maps drawing an external today**. On the candidate, the guard reaches exactly the two boarding-only places. Breaking it back onto the output in the test harness turns the town externals dark, which is the regression written down as an assertion.
- **An empty array is not a declaration.** `destinations: []` is truthy in JavaScript and means nothing, so `hasRoutesKey()` now reads an empty array as absent.
