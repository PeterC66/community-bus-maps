date: 2026-10-17
title: "An admin can retire an old map version from the editor"
---

- **The editor's "Every version of this map" list gains a *Retire this version* button for an admin** on each row the retire rule allows (buses-data OA-622, step 2 of the version-deletion design). A never-published draft asks for a confirmation; a once-published, superseded version asks for a reason, which goes in the audit row, as `prune-versions.mjs --include-published --reason` does. The working head, the published version, the revert target, the highest number and anything awaiting review never get a button. Step-up is required, as on the owner move, because the render folder is removed and there is no un-retire.
- **One rule and one write behind both doors.** Two admin routes, `GET /api/admin/maps/:id/versions/retire-verdicts` and `POST /api/admin/maps/:id/versions/:vid/retire`, ask `classifyVersions()` and a new pure `decideRetire()` in `src/publish/retire.js`. The stamp-then-remove-then-audit write moved out of `scripts/prune-versions.mjs` into `retireVersion()` in `src/publish/retire-write.js`, which the CLI now calls too, so the two cannot drift. The audit row records which door (`via: cli` or `admin-button`).
- **The "its URL will 404" warning was wrong and is corrected.** Every public route serves the map's published key, looked up by slug, so an old `?v=<key>` link gets the current file on the five-minute cache. What retiring a superseded publication loses is the editor's view of it and the option to revert to it; the reason text, the CLI and the `retire.js` comment now say so. The editor's hint "Nothing is ever deleted" now says an administrator can retire a version.
- **Tests.** `test-prune-versions.mjs` gains `decideRetire()` cases and a section 3 that drives both routes in-process and pins the public behaviour (a link carrying a retired key answers 200 with the published file, on the short cache). `prove-red-prune-versions.mjs` points its stamp and audit arms at the shared write and adds a tenth arm for `decideRetire()`; all ten go red. Section 3 was seen red by hand with the route's refusal removed. The route table gains the two routes, both behind the admin guard.
- **Not yet.** The editor's own button, offering a customer only never-published versions, is the rest of OA-622.
