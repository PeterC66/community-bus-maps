date: 2026-09-01
title: "A Must show the sheet could not fit now says so, instead of exiting 0"
---

- **`mustPlace` is not a veto, and the generator was saying so out loud to nobody (OA-216).** `gen_internal.js` ends by comparing the POIs a customer marked *Must show* against the labels the placer actually seated, and writes the difference to stderr — *"3 of 20 must POIs were still not placed on this sheet"*, naming each one. Its own comment calls that "the only thing standing between a classified POI and an answer that failed without saying so". Two siblings sit beside it: a `poi.tiers` key that matched no POI and did nothing, and a rename that collided so two places share one override key and one placer anchor.
- **All three exit 0, and `renderMap.js` read stderr only when the status was non-zero.** They are written with `process.stderr.write` rather than `refuse()` deliberately, because they are not refusals to draw and the sheet is still worth having — so all three take the success path, and on that path the whole stream was discarded unread. `generateSvg()` returned `log: stdout`, which none of them use.
- **So the landmark chooser's promise had a hole in it exactly where it was most expensive.** An editor marks twenty places *Must show*, saves, and is told *"Saved as version 2.3. The map has been redrawn with your choices"* — with three of those choices not applied. The page's soft cap at twelve was a **guess** offered in place of the real answer, which the generator had computed and thrown away. A rename that collided is worse: it is silently sharing an anchor with another POI.
- **`generateSvg()` now returns what the run said, and it costs nothing.** `spawnSync` had captured the stream all along; this touches neither the SVG nor the generator's environment, so the P0 reproduce gate is unaffected — `npm run verify` still reports every sheet byte-identical. It is carried through `renderVersion()` and `previewFrom()` to `/api/maps/:id/save` and `/api/maps/:id/preview`, and shown on the chooser: the save message no longer claims more than the drawing delivered, and the **preview** shows it too, which is the cheapest place to learn it because nothing has been saved yet.
- **The whole stream reaches the server log; only the addressed lines reach the customer.** Most of what a generator writes there — `labels:`, `placeIndex:`, `fit:`, `buildMeta:` — is about engine internals a customer cannot act on, and those are exactly the lines an operator wants when a sheet comes out wrong. So `src/render/genWarnings.js` holds a **list of prefixes with a sentence each**, not a filter of things to hide: a line reaches the editor only if this file names it and says what it means. The generator's own sentence is kept verbatim as the detail, because it names the actual landmarks and the actual remedies, and a paraphrase would lose both.
- **One prefix, three different faults, three different headings.** All three lines start `poi.tiers:`, so a heading chosen by prefix alone would tell a reader *"part of your answer did nothing"* about a placement failure. The suite asserts all three are distinct.
- **STDERR-ON-FAILURE-ONLY IS A CATEGORY ERROR RATHER THAN AN OVERSIGHT**, which is worth recording because it decided the shape of the fix. A guard is only ever as good as the READING of it, and a caller that opens the stream only when the exit status is non-zero has decided in advance that a run which succeeded has nothing to say. That is exactly the reasoning `STRICT_GUARDS` was invented to overturn. The rule: decide what a successful run is allowed to tell you before you decide how to read it.
- **Falsified in both directions** — `npm run test:gen-warnings`, wired into `npm test`. The fixture is built around a **zero exit**, because a test using a failing generator would prove nothing: the failure path always read stderr. Watched red under two mutations — restoring the old reading (the end-to-end case turns, both controls hold), and passing every line through to the customer (the two coverage assertions turn). The controls carry the weight here: a clean run must be silent, and an internal-only run must reach the log and not the editor.
