- **Re-vendors `engine/poi_select.js` and `engine/place/gen_internal.js` from PeterC66/claude-skills#197 (buses-data OA-250).** A tier answer (`poi.tiers`) or an `internal.pois` override may now be keyed `osm:<type>/<id>`, the OpenStreetMap element every landmark has carried since #400, as well as `<category>:<name>`. The `osm:` key is looked up first, so one of two places sharing a name (two Red Lions) can be answered without the other. Nothing writes such a key yet — the chooser still writes `<category>:<name>` — so no sheet changes: the engine's byte gate held all 119 sheet verdicts identical and all 58 working-template sheets byte-identical.
