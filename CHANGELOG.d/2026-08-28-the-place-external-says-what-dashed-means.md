date: 2026-08-28
title: "The place external says what dashed means"
---

- **Seven place externals were drawing a convention they never explained.** `gen_external_places.js` has drawn `limited: true` destinations with a dashed spoke since its first build, and no place sheet said anywhere what dashed meant. The town external gained `design.limitedKeyLabel` on 2026-08-19 for exactly that reason — *"dashed had meant 'certain days only' since the first build and no external sheet said so anywhere"* — and this generator never got it. The backlog row named one place; it is **seven**: both Beaconsfield places, both St Neots places with an external, Ely Co-op and both Godmanchester Co-ops.
- **Same words, same key, same sample.** The row reads from the same `design.limitedKeyLabel` with the same default string as the town sheet, and draws a 12 mm sample at the spoke's own stroke width, dash array and butt cap — so what the key shows and what the map draws cannot drift apart, and the town sheet and the place sheet of one map explain the same thing the same way. Each of the seven gains exactly one label and loses none.
- **The quality ratchet caught what the ink cost, which is the part worth reading.** The bigger opaque legend panel dropped a label on Beaconsfield Simpson Centre (16 → 15, HARD 0 → 1) and buried two more of Ely Co-op's (HARD 3 → 5). Adding ink to fix a defect and creating a defect, exactly as the engine's own gotchas warn.
- **`design.legendPlace` was the lever, and no place had ever set it.** The blank-space search for where to put the panel has existed in this generator all along and was unfed on all twelve places. Measured on all seven: it recovers Simpson Centre's dropped label (HARD back to 0) and takes Ely Co-op to HARD 1 — better than the 3 it carried *before* the row — while changing nothing measurable on the other five. Turned on for those two only, each as a new dated S3 run. Net across the estate: **HARD 320 → 318**, drops unchanged, every byte gate PASS.
- **Five places' `ci-reference/overrides.json` are gone, and that is the orphan-river fix finishing.** Every one contained nothing but `{"internal":{"features":{"river":{"hide":true}}}}` — the suppression the engine stopped needing on 2026-08-27. It lived only in the S4 run folder and no latest S3 has ever carried it, so a rebuild dropped it. Harmless here, and now proven rather than assumed: with the suppression gone, all five rebuilt internal sheets contain no river.
