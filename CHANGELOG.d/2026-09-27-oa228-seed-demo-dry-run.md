- **`scripts/seed-demo.mjs` takes `--dry-run` (buses-data OA-228).** It creates an admin, an approver, three demo organisations with their editors and branding, a pending application, a requested map and a piece of feedback, runs `import-map.mjs` and `propose-update.mjs` as children, and renders and publishes versions, and it had no way to show its plan first. It now reads `confirm('remote')` from `scripts/lib/cli.mjs`: the default is unchanged, and `--dry-run` prints `would create`, `would import`, `would publish` or `would stage` at each step it would have taken, runs no child script, renders nothing and writes no row. New `scripts/test-seed-demo.mjs` (`npm run test:seed-demo`) counts the rows of every table in a throwaway store before and after each run, with a real run as the control; against the old script it fails 5 of its 12 checks. The [operations handbook](docs/H1-operations-handbook.md) names the flag. The fourth of the nine scripts OA-228 lists; one pull request each.
- **Deploy history, written before the deploy per [DEPLOY §3b](docs/DEPLOY.md#3b-the-deploy-history-entry-is-written-before-the-deploy-and-merged-with-it).** This pull request's merge is the commit that goes live. The server does not import `seed-demo.mjs`, so nothing a visitor or a customer sees changes: no schema, route, UI or engine change.
