title: "The sign-in link that reached the container log, a timeout for a hung test, and the move's leftovers"
---

- **A production container with no email provider no longer prints a live sign-in link into its log.** The three admin invite routes (approve an application, invite a user, grant a map to a local adviser) printed the bearer link with `console.log` whenever the email did not go, and "did not go" is exactly what an unset `EMAIL_PROVIDER` produces, in development and in a misconfigured production alike. The sign-in route was already refused in that state; the invite routes were not. All four prints now share one gate, `DEV_CONSOLE_LINKS`, which is "no provider AND not production". The admin's response still carries the link, so an operator holding a customer who cannot sign in still has something to act on. `scripts/test-invite-link-log.mjs` runs an invite and an approval in a child process under `NODE_ENV=production` with no provider and reads the child's real stdout for `token=`; it was seen red against the old routes first, and its control shows the same two routes still print in development (codebase review 2026-10-11, G12).
- **The migration's four warnings reach the structured log.** `src/db/index.js` migrates on import, before the app's Pino logger exists, so a database written by a newer schema, an enum value the guard no longer accepts and a token row that could not be hashed were written to `console` only. The module now records them and `src/server.js` writes them through `app.log` as soon as the app is built; a scripts-only importer (`create-admin`, `import-map`, the tests) still sees them on the console, through a fallback that fires on the next tick (G15).
- **One hung test no longer holds `npm test` to the 15-minute job cap.** `run-tests.mjs` gives every file three minutes, kills one that reaches it, reports it as `TIMEOUT` by name with exit 1, and runs the files after it. Case 7 of `prove-red-run-tests.mjs` patches the limit to half a second and runs a test that sleeps for five (T13). The same harness is now `EXCLUDED` from discovery, because `test.yml` runs it in the step before `npm test` and it was running twice on every push (T12). `build-guide.mjs`, which has taken `confirm('local')` since it was written, is on the `GUARDED` list (C10).
- **The 8 October move to `C:\Buses` is finished in this repository's prose.** Every line that told the reader to run from `C:\Claude\community-bus-maps` — the headers of most test and prove-red scripts, `engine/README.md`, `gate-fixtures/README.md` — says `C:\Buses\community-bus-maps` now. The nine lines naming `C:\Claude\community-bus-maps-ops\` are left alone, because that private folder did not move and they are true. `docs/_archive/` and the dated `CHANGELOG.d/` fragments are history and are untouched; this directory's own README was corrected, because it is an instruction. The three hard-wrapped lines in `DEPLOY.md`'s restore-drill section are one paragraph again (P1, K2).
