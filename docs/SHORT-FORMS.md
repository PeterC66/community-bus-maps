# Short forms used in these documents

<!-- docstamp v1.0 | 2026-09-21 | sha=dbb41633 -->
**v1.0** · updated 21 September 2026

The short forms a reader meets in this repository's live documents that are ours, or particular to buses and public data. Standard computing words — PR, SVG, CI, DNS and the like — are not listed; `.doc-acronyms.json` at the repository root says why, and `check-doc-acronyms.mjs` fails when a document uses a short form that is in neither place. The changelog and `docs/_archive/` are dated history and are not checked.

| Short form | In full | What it means here |
|---|---|---|
| **BODS** | Bus Open Data Service | The Department for Transport's national feed of bus timetables, routes and fares, which every map is built from |
| **CIC** | Community Interest Company | The not-for-profit company form BusMaps.uk is being set up as |
| **CTA** | Call To Action | The button or link a page asks a visitor to press |
| **GTFS** | General Transit Feed Specification | The standard file format BODS publishes timetables in |
| **OA** | Open Action | A numbered item in the project's backlog, written `OA-nnn`, kept in the private `buses-data` repository |
| **OGL** | Open Government Licence | The licence much UK public data, including BODS and NaPTAN, is published under |
| **OSM** | OpenStreetMap | The open map the streets, rivers and landmarks on every map are drawn from |
| **PII** | Personally Identifiable Information | Anything that identifies a person, which this repository keeps out of git |
| **POI** | Point Of Interest | A landmark drawn on a map — a school, a surgery, a supermarket |
| **SLA** | Service Level Agreement | A written promise of how quickly something will be done |
| **VPS** | Virtual Private Server | The rented Linux host that serves busmaps.uk |
| **WCAG** | Web Content Accessibility Guidelines | The accessibility standard the public site is measured against |
